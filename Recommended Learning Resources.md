# Recommended Learning Resources

Use the official documentation as the source of truth for APIs and version-specific behavior. Tutorials and courses can make a useful introduction, but check their supported Java and Spring versions before following along.

## Java

- [Dev.java learning materials](https://dev.java/learn/) — language tutorials and learning paths.
- [Java Platform documentation](https://docs.oracle.com/en/java/) — API and platform references.
- [Amigoscode](https://www.youtube.com/@amigoscode), [Bro Code](https://www.youtube.com/@BroCodez), and [Telusko](https://www.youtube.com/@Telusko) — video-based learning options.

## Spring and Spring Boot

- [Spring Boot reference documentation](https://docs.spring.io/spring-boot/reference/) — configuration, features, and supported behavior.
- [Spring Guides](https://spring.io/guides) — focused, hands-on introductions.
- [Spring Framework reference](https://docs.spring.io/spring-framework/reference/) — core framework concepts.
- [Baeldung](https://www.baeldung.com/) — tutorials and examples; check article dates and framework versions.
- [Dan Vega](https://www.danvega.dev/) — Spring and Java tutorials.

## Databases and SQL

- [PostgreSQL documentation](https://www.postgresql.org/docs/)
- [MySQL documentation](https://dev.mysql.com/doc/)

## Containers

- [Docker documentation](https://docs.docker.com/)
- [Docker Get Started](https://docs.docker.com/get-started/)

## Git and GitHub

- [Git documentation](https://git-scm.com/doc)
- [Pro Git book](https://git-scm.com/book/en/v2)
- [GitHub Flow](https://docs.github.com/en/get-started/using-github/github-flow)

## Optional courses

The courses below are third-party, may be paid, and are not prerequisites. Review their current curriculum, cost, and supported versions before enrolling.

- [Java Development for Beginners (Udemy)](https://www.udemy.com/course/java-development-for-beginners-learnit)
- [Spring and Hibernate Tutorial (Udemy)](https://www.udemy.com/course/spring-hibernate-tutorial)
